# Default logging directory for the SCMTERM - Small Computer Monitor TERMinal
Location: https://github.com/hp35/z80/tree/main/scmterm/log

This is the default logging directory for the bash script `SCMTERM` for
interfacing the Small Computer Monitor (SCM) running on the RC2014 Z80
single card computer from a standard terminal.
